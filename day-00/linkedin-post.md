Starting something new tomorrow: 15 days of learning blockchain development, in public. 🔗

I've spent 4 years building web apps and leading dev teams. Blockchain has been on my list for a while, so I'm giving it a structured sprint — from hashing and building a toy blockchain from scratch, all the way to Solidity smart contracts and a full dApp on the Ethereum testnet.

The plan:
→ Days 1–6: the fundamentals — hashing, blocks, proof of work, wallets, transactions, Merkle trees
→ Days 7–11: Ethereum, Solidity, ERC-20 tokens, NFTs, testing
→ Days 12–15: frontend + wallet, a deployed dApp, security, final project

Every day's code goes into its own folder on GitHub, and I'll share progress here morning and evening.

Repo: https://github.com/Khadka1996/Learning-Blockchain
